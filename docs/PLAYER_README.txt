LOST OBJECTS  (public beta)
===========================

Finds every craftable workshop item that cannot be reached in the build menu -
from mods, DLCs or the base game - and puts it back: into the existing category
it belongs to, into a "Lost Objects" folder in the mod's own menu, or - if it
has no home at all - into the "Lost Objects" tab of the main workshop menu.

VIBECODED BY AI: The code of this mod was written by Claude (Anthropic), an AI
model, directed and tested by egnutv. AI-generated code can contain mistakes.
Keep a backup save.

REQUIREMENTS
- Fallout 4 1.11.240 (tested); 1.10.984 and 1.10.163 supported but untested
- F4SE 0.7.9 for 1.11.240 (or the version matching your game)
- Address Library for F4SE Plugins matching your game version

INSTALLATION
Install with your mod manager and enable LostObjects.esp (light plugin).
The first time (and after you changed your mods), wait about 20 seconds after
loading a save before you enter workshop mode. If you are faster, a message
asks you to restart the game once. After that the menus are complete at once.

SETTINGS
The holotape "Lost Objects Settings" in your inventory (added automatically,
or craft it for free at the chemistry station):
rebuild the menus now and switch the main options on or off.
All options: Data\F4SE\Plugins\LostObjects.ini

FILES FOR BUG REPORTS
Documents\My Games\Fallout4\F4SE\LostObjects.log
Documents\My Games\Fallout4\F4SE\LostObjects_Report.txt
(bDevelopmentMode=1 in the INI writes more detailed files)

FILES AND PRIVACY
Lost Objects does not go online and collects no personal data.
It writes small files to Documents\My Games\Fallout4\F4SE\
(log, report, snapshot of the menus, holotape choices). Your mod manager
does NOT remove them: to remove every trace, delete every file there whose
name starts with "LostObjects". Full list: docs/FILES_AND_PRIVACY.md on GitHub.
