LOST OBJECTS
============

Finds every craftable workshop item that cannot be reached in the build menu -
from mods, DLCs or the base game - and collects it in a new workshop tab called
"Lost Objects".

VIBECODED BY AI: The code of this mod was written by Claude (Anthropic), an AI
model, directed and tested by egnutv. AI-generated code can contain mistakes.
Keep a backup save.

REQUIREMENTS
- Fallout 4 1.11.191 or newer (target 1.11.240), 1.10.984 or 1.10.163
- F4SE matching your game version
- Address Library for F4SE Plugins matching your game version

INSTALLATION
Install with your mod manager and enable LostObjects.esp (light plugin).

SETTINGS
Data\F4SE\Plugins\LostObjects.ini

FILES FOR BUG REPORTS
Documents\My Games\Fallout4\F4SE\LostObjects.log
Documents\My Games\Fallout4\F4SE\LostObjects_Report.txt
