# Contributing

Contributions, forks and ports are welcome - see the additional permissions in
[NOTICE.md](NOTICE.md). You do not need to ask before forking or continuing the project.

- Bug reports: use the issue template and attach `LostObjects.log` and
  `LostObjects_Report.txt`.
- Code: keep the style of the existing files (`.clang-format`), explain in the pull
  request how you tested in game.
- The plugin file `data/LostObjects.esp` is generated: change
  `tools/build_plugin.py`, never the .esp itself.
- Contributions are published under the project's license.

There is no guaranteed review or support. The original code was written by an AI
(Claude, Anthropic) and tested by egnutv.
