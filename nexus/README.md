# Nexus Mods page kit

| File | Use |
|---|---|
| `description.bbcode` | the mod page description - paste it into the description editor (BBCode mode) |
| `page_fields.md` | every other field: name, summary, category, requirements, tags (incl. the required AI tags), permissions, file upload |
| `screenshots.md` | which screenshots to take and how |
| `header.png` | optional primary image (1920 x 1080), made by `tools/icon/make_nexus_header.py` from `Logo/Logo.png` |

The mod archive itself is `releases/LostObjects-<version>.zip`.
