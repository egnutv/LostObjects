# Screenshots for the Nexus page

Nexus shows images in a gallery; the first one is the primary image (thumbnail in
search results, 16:9 works best). 1920 x 1080 is ideal. Take them in a settlement with
good daylight (for example Sanctuary at noon), HUD on, so the menu path is visible.
English game language reaches more people, but German screenshots are fine too.

| # | What | How | Why |
|---|---|---|---|
| 1 | **Primary image** | `header.png` from this folder, or your best in-game shot | first impression in search results |
| 2 | **The logo in the main workshop menu** | open the workshop, scroll the top bar to "Lost Objects" so the logo is selected | shows the new tab and the icon |
| 3 | **A "Lost Objects" folder in a mod's menu** | e.g. Snappy Builds > Lost Objects, the folder selected at the end of the bar | the main idea: lost items go back to their mod |
| 4 | **Inside that folder** | the groups (Wallpapers, Walls, Roof, Snappy_DLC03, ...) | automatic grouping |
| 5 | **An item sorted into an existing category** | e.g. a Bobblehead in OCDecorator > Entertainment, or Aktenschrank / File Cabinet in Furniture > Containers | items land next to their siblings |
| 6 | **A recovered item being placed** | a lost item selected with its 3D preview and costs | it is a normal buildable item, original costs |
| 7 | **The Lost Objects tab** | main menu > Lost Objects, a folder open | what has no home anywhere |
| 8 | **Before / after** (optional, very convincing) | the same menu with the mod disabled and enabled | shows the problem and the fix |
| 9 | **The AI notice** (optional) | the message box on the first load | transparency |
| 10 | **The report** (optional) | `LostObjects_Report.txt` opened in Notepad, the summary at the top | shows what the mod found |

Tips:

- Hide personal things (Windows user name in paths, other windows) - for the report
  screenshot, crop to the text.
- Nexus caption for each image: one short sentence, e.g. "Lost pieces of Snappy HouseKit
  go into a Lost Objects folder at the end of its own menu."
- A short video (30-60 s, YouTube link in the Videos tab) helps a lot: enter workshop,
  show the logo tab, open a mod's Lost Objects folder, build one recovered item.
